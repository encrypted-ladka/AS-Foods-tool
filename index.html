🔵 Google Drive Setup Guide

Yeh ek baar ka 2-minute setup hai. Phir kabhi nahi karna.
  1. Jaao: console.cloud.google.com
  2. New Project create karo (naam kuch bhi — e.g. "AS Foods")
  3. Left menu → APIs & Services → OAuth consent screen
    User Type: External → Create → App name fill karo → Save
  4. Left menu → APIs & Services → Credentials
    → + Create Credentials → OAuth Client ID
  5. Application type: Web application
    Authorized origins mein add karo: http://localhost aur null
  6. Create dabao → Client ID copy karo (ends in .apps.googleusercontent.com)
  7. Woh Client ID yahan paste karo aur Save karo ✓
⚠️ Important: Google Drive API bhi enable karna hoga:
APIs & Services → Library → "Google Drive API" search karo → Enable
